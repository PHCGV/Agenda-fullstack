 📅 Agenda Fullstack

Uma aplicação fullstack desenvolvida para gerenciamento de compromissos, tarefas e organização pessoal.  
O projeto integra frontend, backend e banco de dados em uma estrutura moderna e escalável.

🚀 Acesse o Projeto Online

🌐 Deploy Oficial

🔗 https://agenda-fullstack-front.vercel.app/

 Funcionalidades

✅ Cadastro de usuários  
✅ Sistema de login  
✅ Criação de compromissos  
✅ Edição de tarefas  
✅ Exclusão de eventos  
✅ Organização da agenda  
✅ Integração Fullstack  
✅ Persistência de dados  

🛠️ Tecnologias Utilizadas

🎨 Frontend
- HTML
- CSS
- JavaScript

⚙️ Backend

- Express.js

 🗄️ Banco de Dados
